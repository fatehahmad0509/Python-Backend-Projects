MessageLMS - Web Edition
This project is the web-based version of the MessageLMS application I previously developed. It is a real-time messaging platform that offers a Discord-like experience. While focusing on speed and efficiency on the backend, the frontend aims for a completely user-friendly and mobile-responsive structure.

Key Features
Real-Time Communication: Instant message delivery using WebSocket technology.

Instant Notifications: The system now sends browser notifications for incoming messages so you never miss a chat!

Modern Database: Neon Database (PostgreSQL) is used for efficient data management.

Mobile Friendly (Responsive): A layout suitable for all screen sizes with a hamburger menu.

Fast Infrastructure: High-performance asynchronous operation with the Python-based FastAPI framework.

User Oriented: A smooth interface designed for a seamless user experience.

Message deletion and editing

WhatsApp-style read receipts

Number of active users and list of active users

Customized notification sound



Technologies Used
Backend: Python, FastAPI

Frontend: HTML5, CSS3, JavaScript (Notification API)

Database: Neon DB (PostgreSQL)

Communication: WebSocket

Development Notes
This project was developed with a focus on modern software practices. AI assistance was utilized specifically for frontend design, connection logic, and communication protocols to ensure high code quality and minimize potential bugs. The system is currently running perfectly and stable. My goal was to make the previous Message LLM experience more accessible by moving it to the browser.
