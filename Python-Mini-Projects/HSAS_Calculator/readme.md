🎓 High School Achievement Score (HSAS) Calculator

A simple Python console application that calculates a student's High School Achievement Score (HSAS) based on written and oral exam grades.

🚀 Features
👨‍🎓 Student name input system
📝 2 written exam grades
🗣️ 2 oral exam grades
📊 Automatic average calculation (HSAS)
⚡ Lightweight Python console tool
🧠 How It Works

The program collects 4 grades:

First written exam
Second written exam
First oral exam
Second oral exam

Then calculates the average:

HSAS = (written1 + written2 + oral1 + oral2) / 4
📦 Example Usage
Welcome to the High School Achievement Score (OBP) Calculator! Please enter the student's full name: Fatih

Enter Fatih's first written exam grade: 80
Enter the second written exam grade: 90
Enter the first oral exam grade: 70
Enter the second oral exam grade: 85

Fatih's High School Achievement Score (HSAS) = 81.25
