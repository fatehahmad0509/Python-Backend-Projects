# ⚖️ BMI Calculator (Python CLI)

This is a simple Body Mass Index (BMI) calculator built with Python.  
It takes user input for weight and height, calculates BMI, and returns the health category.

---

## 🚀 Features

- Takes user weight (kg)
- Takes user height (meters)
- Calculates BMI automatically
- Displays BMI category

---

## 🧠 BMI Categories

- Underweight: BMI ≤ 18.5  
- Normal: 18.5 – 24.9  
- Overweight: 25 – 29.9  
- Obese: BMI ≥ 30  

---
