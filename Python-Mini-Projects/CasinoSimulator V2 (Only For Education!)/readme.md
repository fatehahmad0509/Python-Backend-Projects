# 🎰 Casino Simulator V2

A Python-based casino simulation featuring multiple game modes, balance management, and leverage-based rewards.

Players can test their luck through different games while managing their virtual bankroll.

---

## 🎮 Available Games

### 🎲 Dice Roll

Guess the outcome of a six-sided dice.

### 🔢 Number Guess

Try to predict a randomly generated number between 1 and 20.

### 🪙 Heads or Tails

Choose between Heads or Tails and test your luck.

* Multiple casino game modes
