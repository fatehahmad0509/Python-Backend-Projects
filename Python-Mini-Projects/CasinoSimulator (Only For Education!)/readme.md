# 🎰 Casino Simulator

A simple casino simulation game built with Python.

Players can choose between multiple gambling-style games, place bets, and try to grow their balance using different leverage levels.

---

## 🎮 Game Modes

### 🎲 Dice Game

* Guess the result of a dice roll (1-6)
* Win rewards for correct guesses
* Lose balance for incorrect guesses

### 🔢 Number Guess

* Guess a randomly generated number between 1 and 20
* Earn rewards for successful predictions

### 🪙 Heads or Tails

* Choose between Heads or Tails
* Test your luck with a virtual coin flip

---

## 🚀 Features

* Multiple game modes
* Configurable leverage system
* Balance management
* Randomized outcomes
* Simple command-line interface

## 💡 Gameplay

1. Enter your leverage multiplier.
2. Enter your starting balance.
3. Choose a game mode.
4. Continue playing until your balance reaches zero.
