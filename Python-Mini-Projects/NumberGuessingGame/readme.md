🎯 Number Guessing Game (Simple Version)

A beginner-friendly Python number guessing game where the player tries to guess a randomly selected number based on difficulty level.

🚀 Features
🎲 Random number generation
🎚️ 3 difficulty levels
🧠 Instant win/lose feedback
⚡ Simple one-try gameplay
💻 Console-based interaction
🎮 Difficulty Levels
Mode	Range
Easy	1 - 10
Medium	1 - 20
Hard	1 - 50
🧠 How It Works
User selects difficulty
Program picks a random number in that range
User makes a single guess
Program checks result immediately
📦 Example Usage
🎚️ Difficulty selection
Welcome to the Number Guessing Game! I will think of a number and you will try to guess it. But first, choose a difficulty mode! 1 = Easy, 2 = Medium, 3 = Hard.
🎯 Game start
I picked a number between 1 and 20!
Please Write Your Guess: 14
🏆 Win
Congratulations! Your answer is correct!
💀 Lose
Unfortunately, you guessed wrong! The number I chose was: 17
