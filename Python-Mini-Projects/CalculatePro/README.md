# 🧮 CalculatePro

CalculatePro is a modern calculator application built with Python and Tkinter.

Inspired by modern mobile calculator interfaces, the project features a custom-designed graphical user interface, interactive buttons, and a clean user experience.

---

## 🚀 Features

* Modern calculator interface
* Addition, subtraction, multiplication, and division
* Decimal number support
* Percentage calculations
* Positive / negative number conversion
* Custom button rendering using Pillow (PIL)
* Hover animations and visual effects
* High-DPI display support on Windows

---

## 🖥️ Technologies Used

* Python
* Tkinter
* Pillow (PIL)

## ▶️ How to Run

1. Install dependencies:

```bash
pip install pillow
```

2. Start the application:

```bash
python main.py
```
