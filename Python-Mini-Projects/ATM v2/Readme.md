🏦 ATM Simulation (Python CLI)

This is a simple ATM simulation project written in Python.  
It allows users to perform basic banking operations through a command-line interface.

🚀 Features

- Deposit money
- Withdraw money
- Check balance
- Send money (simulated)
- Request money (with random approval system)
- Persistent balance storage using a file (`balance.txt`)


🧠 How It Works

The program stores the user's balance in a local file (`balance.txt`).  
Each transaction updates the balance and saves it automatically.

Some features like "Request Money" use random outcomes to simulate real-world uncertainty.

▶️ How to Run

1. Make sure you have Python installed (3.x recommended)
2. Run the script:
python main.py
