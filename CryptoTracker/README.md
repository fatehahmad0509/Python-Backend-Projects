# ₿ CryptoTracker

A modern cryptocurrency tracking application built with Python and CustomTkinter.

CryptoTracker displays live market prices for the top cryptocurrencies using real-time data from the CoinGecko API, featuring automatic updates and a modern desktop interface.

---

## 🚀 Features

* Live cryptocurrency prices
* Top 10 cryptocurrencies
* Automatic refresh every 10 seconds
* Real-time market monitoring
* Price change indicators
* Modern dark-themed interface
* Responsive card-based layout
* Multi-threaded data fetching

---
